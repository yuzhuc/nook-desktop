## 屏幕覆盖

- 截图：`a5-overlay.png`（顶部）、`a6-overlay2.png`（滚动后）、实时窗口底部补图。
- 页面标题：`屏幕覆盖`。
- 分组标题：`开启屏幕覆盖`、`开启编辑模式`、`显示设置`、`常见问题`。
- 行：
  - `开启屏幕覆盖 → 开关（关）`；说明为“允许在屏幕最上方显示正在说话的用户，可能需要管理员权限；进入语音频道后会显示屏幕覆盖窗口”。
  - `快捷键开启/关闭屏幕覆盖 → 未设置`。
  - `开启编辑模式 → 开关（关）`；说明为“开启后，可以直接调整屏幕覆盖窗口的尺寸和位置”。
  - 显示设置使用单选项：`显示所有用户`（已选）、`只显示正在说话的用户`（未选）。
- 常见问题结构：FAQ 标题 + 编号步骤。
  - `屏幕覆盖窗口不显示，或者无法覆盖到游戏画面上面`
    1. 检查本页顶部第一个模块【开启屏幕覆盖】，确保开关已开启。
    2. 关闭客户端，右键 Oopz 启动图标，点击【以管理员身份运行】。
    3. 检查游戏的显示设置，将游戏设置为【无边框全屏】。
  - `开启/关闭屏幕覆盖的快捷键无效`
    - 说明为“关闭客户端，右键 Oopz 启动图标，点击【以管理员身份运行】”；实时窗口确认此处为页面末端。
- 滚动条：有；实时窗口已滚到底。
- 高度估算：约 2 屏，1–2 次滚动。
