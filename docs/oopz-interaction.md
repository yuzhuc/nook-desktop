## 域设置（⋮ → 域设置）

OOPZ 里是**整页**：左栏域图标照旧，频道栏换成设置导航，右边是内容。

- 导航：`‹ 返回` / 分组「域设置」{基本信息、身份组、管理日志} / 分组「成员管理」{成员、封禁} / 底部「删除域」（红字）
- **基本信息**：`ⓘ 基本信息`；域头像（圆角方图 + 「可上传小于 10 MB 的 PNG、JPG」「域等级达到 LV.3 后可上传 GIF、WEBP 格式的动态头像」+ 上传域头像）；域名称（下划线字段 + 修改域名称）；域横幅（说明 + 建议至少 436×260 + 预览图 + 上传域横幅）；域介绍（暂无介绍 + 修改域介绍）；域搜索设置（设置用户将如何搜索到你的域 / 允许通过 ID 搜索域加入 ›）
- **身份组**：「创建身份组」蓝按钮 + 提示「拖动调整身份组等级排序，点击名称即可编辑信息/权限」+ 表头「身份组 5/100 | 描述 | 成员列表显示 | 操作」+ 行：域主（域的所有者）、高级管理员、管理员、嘉宾、全体成员（域的默认身份组）
- **管理日志**：说明「记录域内的管理操作，当前支持查看【移出域】【封禁】【用户加入退出域】的操作记录」+「全部 ›」+ 空状态「暂无管理记录」
- **成员**：搜索成员 / 全体成员 / 排序 ↑ + 表头「成员 - N | 身份组 | 活跃分（本月/累计）| 成员加入时间」
- **封禁**：空状态「暂无封禁成员」

我们的现状（`Views/Room/RoomView.axaml` 里的 `GroupSettingsPage`）：五个分栏都摆好了，基本信息的头像 / 名称 / 横幅 / 介绍 / 搜索设置、身份组表格、管理日志与封禁的空状态、成员列表都在。**上传域头像、修改域名称、上传域横幅、修改域介绍、创建身份组、删除域只做了样式，还没接功能。**

## 没确认的

- ☰ 顶栏图标到底打开什么（那一次页面已经是账号设置页）。
- ✂ 和 ⊕ 按下会触发截图 / 录制面板，怕影响桌面没敢点。
- 语音频道只右键、没左键（会真的进语音）。
- 消息区右键没试出菜单。
- OOPZ 的私信页入口没找到：左栏只有发现 / 商城 / 加速器，顶栏第 4 个气泡点开是搜索浮层。你的 OOPZ 有私信页的话指我一下入口在哪。
